# 👻 Модуль безпеки Ghost
**Інструмент зміцнення безпеки Windows і Azure на базі PowerShell**

> **Проактивне зміцнення безпеки для кінцевих точок Windows та середовищ Azure.** Ghost надає функції зміцнення на базі PowerShell, які можуть допомогти зменшити поширені вектори атак шляхом відключення непотрібних служб та протоколів.

## ⚠️ Важливі застереження

**ПОТРІБНЕ ТЕСТУВАННЯ**: Завжди спочатку тестуйте Ghost у невиробничих середовищах. Відключення служб може вплинути на законні бізнес-функції.

**НЕМАЄ ГАРАНТІЙ**: Хоча Ghost націлений на поширені вектори атак, жоден інструмент безпеки не може запобігти всім атакам. Це один компонент комплексної стратегії безпеки.

**ОПЕРАЦІЙНИЙ ВПЛИВ**: Деякі функції можуть впливати на функціональність системи. Уважно перегляньте кожне налаштування перед розгортанням.

**ПРОФЕСІЙНА ОЦІНКА**: Для виробничих середовищ консультуйтеся з фахівцями з безпеки, щоб переконатися, що налаштування відповідають потребам вашої організації.

## 📊 Ландшафт безпеки

Збитки від програм-вимагачів досягли **57 мільярдів доларів у 2025 році**, а дослідження показують, що багато успішних атак експлуатують базові служби Windows та неправильні конфігурації. Поширені вектори атак включають:

- **90% інцидентів з програмами-вимагачами** пов'язані з експлуатацією RDP
- **Уразливості SMBv1** дозволили атаки на кшталт WannaCry та NotPetya
- **Макроси документів** залишаються основним методом доставки шкідливого ПЗ
- **USB-атаки** продовжують націлюватися на повітряно-розірвані мережі
- **Зловживання PowerShell** значно зросло в останні роки

## 🛡️ Функції безпеки Ghost

Ghost надає **16 функцій зміцнення Windows** плюс **інтеграція безпеки Azure**:

### Зміцнення кінцевих точок Windows

| Функція | Призначення | Міркування |
|----------|---------|----------------|
| `Set-RDP` | Керує доступом до віддаленого робочого столу | Може вплинути на віддалене адміністрування |
| `Set-SMBv1` | Контролює застарілий протокол SMB | Потрібен для дуже старих систем |
| `Set-AutoRun` | Контролює AutoPlay/AutoRun | Може вплинути на зручність користувача |
| `Set-USBStorage` | Обмежує USB-накопичувачі | Може вплинути на законне використання USB |
| `Set-Macros` | Контролює виконання макросів Office | Може вплинути на документи з підтримкою макросів |
| `Set-PSRemoting` | Керує віддаленим доступом PowerShell | Може вплинути на віддалене керування |
| `Set-WinRM` | Контролює Windows Remote Management | Може вплинути на віддалене адміністрування |
| `Set-LLMNR` | Керує протоколом розв'язання імен | Зазвичай безпечно відключати |
| `Set-NetBIOS` | Контролює NetBIOS через TCP/IP | Може вплинути на застарілі програми |
| `Set-AdminShares` | Керує адміністративними спільними ресурсами | Може вплинути на віддалений доступ до файлів |
| `Set-Telemetry` | Контролює збір даних | Може вплинути на діагностичні можливості |
| `Set-GuestAccount` | Керує гостьовим обліковим записом | Зазвичай безпечно відключати |
| `Set-ICMP` | Контролює відповіді ping | Може вплинути на діагностику мережі |
| `Set-RemoteAssistance` | Керує віддаленою допомогою | Може вплинути на роботу служби підтримки |
| `Set-NetworkDiscovery` | Контролює виявлення мережі | Може вплинути на перегляд мережі |
| `Set-Firewall` | Керує брандмауером Windows | Критично для безпеки мережі |

### Безпека хмари Azure

| Функція | Призначення | Вимоги |
|----------|---------|--------------|
| `Set-AzureSecurityDefaults` | Вмикає базову безпеку Azure AD | Дозволи Microsoft Graph |
| `Set-AzureConditionalAccess` | Налаштовує політики доступу | Ліцензування Azure AD P1/P2 |
| `Set-AzurePrivilegedUsers` | Аудитує привілейовані облікові записи | Дозволи Global Admin |

### Варіанти корпоративного розгортання

| Метод | Випадок використання | Вимоги |
|--------|----------|--------------|
| **Пряме виконання** | Тестування, малі середовища | Права локального адміністратора |
| **Групова політика** | Доменні середовища | Адміністратор домену, керування GP |

```powershell

Set-Ghost -SMBv1 -RDP -USBStorage -Intune
```

## 🔍 Деталі функцій

### Основні функції зміцнення

#### Мережеві служби
- **RDP**: Блокує доступ до віддаленого робочого столу або рандомізує порт
- **SMBv1**: Відключає застарілий протокол спільного використання файлів
- **ICMP**: Запобігає відповідям ping для розвідки
- **LLMNR/NetBIOS**: Блокує застарілі протоколи розв'язання імен

#### Безпека додатків
- **Макроси**: Відключає виконання макросів у додатках Office
- **AutoRun**: Запобігає автоматичному виконанню з знімних носіїв

#### Віддалене керування
- **PSRemoting**: Відключає віддалені сеанси PowerShell
- **WinRM**: Зупиняє Windows Remote Management
- **Remote Assistance**: Блокує з'єднання віддаленої допомоги

#### Контроль доступу
- **Admin Shares**: Відключає спільні ресурси C$, ADMIN$
- **Guest Account**: Відключає доступ гостьового облікового запису
- **USB Storage**: Обмежує використання USB-пристроїв

### Інтеграція Azure
```powershell
# Підключитися до орендаря Azure
Connect-AzureGhost -Interactive

# Увімкнути типові налаштування безпеки
Set-AzureSecurityDefaults -Enable

# Налаштувати умовний доступ
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# Аудитувати привілейованих користувачів
Set-AzurePrivilegedUsers -AuditOnly
```

### Інтеграція Intune (нова у v2)
```powershell
# Підключитися до Intune
Connect-IntuneGhost -Interactive

# Розгорнути через політики Intune
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## 🎯 Приклади сценаріїв атак

Хоча Ghost націлений на поширені вектори атак, конкретна профілактика залежить від правильної реалізації та тестування:

### Атаки в стилі WannaCry
- **Пом'якшення**: `Set-Ghost -SMBv1` відключає вразливий протокол
- **Міркування**: Переконайтеся, що жодна застаріла система не потребує SMBv1

### Програми-вимагачі на основі RDP
- **Пом'якшення**: `Set-Ghost -RDP` блокує доступ до віддаленого робочого столу
- **Міркування**: Можуть знадобитися альтернативні методи віддаленого доступу

### Шкідливе ПЗ на основі документів
- **Пом'якшення**: `Set-Ghost -Macros` відключає виконання макросів
- **Міркування**: Може вплинути на законні документи з підтримкою макросів

### USB-доставлені загрози
- **Пом'якшення**: `Set-Ghost -USBStorage -AutoRun` обмежує функціональність USB
- **Міркування**: Може вплинути на законне використання USB-пристроїв
